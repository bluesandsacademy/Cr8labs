Mechanism

Hero section pins with position: sticky while its scroll container advances. Ring scale, opacity and the render crossfade are driven off scroll progress (CSS scroll-driven animations / animation-timeline: view() where supported, an IntersectionObserver-based fallback elsewhere). No JS-driven layout thrash.

Reduced motion

prefers-reduced-motion swaps the scroll-driven transform for a simple opacity crossfade between frame 1 and frame 3, no pinning, no scale. Same on low-end devices per the offline-first, entry-level-device positioning in the copy deck.

Scope

This is a Home-page-only signature moment, not a pattern repeated on inner pages, consistent with "spend the boldness in one place." Build it once the Main hero layout above is approved.
